# Интернет-магазин - Bootstrap проект

Проект для домашнего задания по верстке с использованием Bootstrap 5.

## Структура проекта
- `app.py` - веб-сервер на Python
- `templates/` - HTML шаблоны
  - `base.html` - базовый шаблон с меню
  - `index.html` - главная страница
  - `catalog.html` - страница каталога
  - `category.html` - страница категории
  - `contacts.html` - страница контактов
- `static/css/` - статические файлы CSS

## Запуск проекта
```bash
python app.py
